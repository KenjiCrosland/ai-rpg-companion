**Trigger:** the "Path Classification and the Five Pipelines" brief (critic, 2026-10-18),

Nothing here changes a sheet.

## How the engine decides what it is building today

There is no path. Six variables, set in six places, gate the stages:

| variable | set where | means |
|---|---|---|
| `pcPlain.exact` → `printExact` | `printCanonFor` (reskin/generate.mjs ~1806): a whole print name, no addition | exact print |
| `pcPlain.borrowOnly` → `printBody && !printPlain` | the same matcher: print name + addition, a hyphenated head, a prefix, or an NPC-class head (`npcHead`) | borrow |
| `pcPlain === null` | the matcher found nothing, or `speciesOutranks` / `typeOutranks` / `canonRejected` vetoed it | homebrew |
| `pcRoute` | a SECOND matcher call at route time (~1444), same vetoes, overrides the resolve call's archetype ("print canon route") | — |
| `body` | the Vue's `bodyType` (ooze / swarm / dragon) → donor pool | chassis parameter |
| `ck` / `sk` | class kit (key table or the identity call's `implied_class`), species kit; both `printExact ? null : …` | kit parameters |

The identity call (provided_name, type_source, implied_class, size, movement, attack_mode, mind)
and the resolve call (archetype, style, creature_type, mechanics, `cue_verdicts` — this IS the
brief's "hint call", riding as questions on the resolve call) run for every non-blank prompt,
including an exact print name, and their answers are then overruled on print bodies. A blank
roll is a synthesis call in the Vue whose text enters the engine as an ordinary concept —
**no flag reaches generate.mjs**. Per-row re-roll is a separate module
(`format-2024/generate.mjs: rerollEntry / rerollSection`) outside this pipeline entirely.

## Merging identical lists

- **exact ≠ borrow.** They differ in eight stages (kits, parts, both seats, catalog, value
  floor, fallback, repair). Two paths.
- **borrow ≠ homebrew.** They differ in print body load, numbers-near-CR, chassis rows and
  nova leaving, the `gmAsked` receipt gate on both seats, `standDownT`, resistances withheld,
  the legendary kit. Two paths.
- **class NPC = borrow, today.** An NPC-class head ("a kuo-toa priest", "a templar priest")
  matches the Priest and runs the borrow list: NPC body + species kit + class kit + both seats
  + value floor + fallback. The brief's class-NPC list (kit rows never evicted, no filler, no
  seeds, one receipted seat) is stage 4's TARGET; no stage in the code distinguishes it from a
  monster borrow yet. One path today; a fourth by intent.
- **blank = homebrew.** No flag reaches the engine; the synthesis call is a Vue-side prefix.
  A parameter, not a path.
- **swarm / dragon / ooze body = homebrew minus the fallback shelf** (`!body` at the shelf,
  "a body chassis is a complete kit"). By the brief's strict criterion that one stage makes it
  a path; I read it as a chassis parameter whose pool has no shelf. Owner's call; I recommend
  parameter.
- **far-CR borrow** (the CR 6 skeleton) is the borrow list with `near = false`: print's
  numbers do not land and the chassis nova stays. A parameter.
- **re-roll** is not on this pipeline at all. Its own list is the brief's open question.

## Recommendation for step 2

Have the dispatcher populate the SAME fields the engine already reads — `pc.exact`,
`pc.borrowOnly`, `pc.npcHead`, `pc.name`, plus `ck`/`sk` eligibility — from the validated path
call, and leave the ~80 readers alone. Run it behind the matcher first: both compute, the
trace prints `[path] …` and a `[path] disagrees:` line where they differ, no sheet changes.

right, before any pipeline is tightened.

## Owner's rulings at the step-3 stop point (2026-10-19)
1. No vote; start building. 2. A title is meaningful — a knight is a class, and "king" or "tyrant"
implies a leader with minions — so a title on an invented creature is a LEADER signal carried as
a `title` field (homebrew path), not a class; a personal name alone stays class NPC. 3. The
Berserker label is lenient: the print Berserker or a close homebrew, either is fine.
