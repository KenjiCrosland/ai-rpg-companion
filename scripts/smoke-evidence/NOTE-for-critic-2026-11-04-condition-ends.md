# Note for the critic — a condition that doesn't say when it ends

Short version: **"a row that imposes a condition states when it ends" is not print's
rule**, so please don't score a block down for it without checking the three cases below.
We measured print to settle this.

**Prone and Petrified never state an end.** Print imposes Prone 10 times and states an
end 0 of 10 — a creature just stands up for half its movement. Petrified: 0 of 4, because
it's terminal by design (a statue until Greater Restoration). A row reading *"the target
has the Prone condition."* and stopping is print-exact.

**A condition can piggyback on another, and the parent's end is the child's.** Print:
*"While Poisoned, the target has the Paralyzed condition"* (Chuul, Phase Spider, Vampire
Familiar), *"While the cloaker is attached, the target has the Blinded condition."* There
is no separate end clause because there doesn't need to be one.

**The end is often not in the sentence that imposes the condition.** The Kraken's Swallow
and the Ghost's Possession both state their end further down the row.

Also: print writes **"repeats the save"**, not "repeats the saving throw" — that phrase is
an end clause. (It caught us out; we'd scored the Harpy, both Silver Dragons, the Chuul
and the Doppelganger as end-less on that wording alone.)

With those three allowances, **all 107 of print's condition-imposing rows state an end,
and 0 are flagged.** On our side the same test finds **0 of 210 rows and 0 of 513 sheets**
— the engine always states an end today. So if you do find a row with a genuinely missing
end on a non-Prone, non-Petrified, non-piggybacked condition, that's a real find worth
flagging by name, not a systemic weakness. Print's own residue is one row: the Quasit's
Scare, plus three open-ended Poisoned bites (Death Dog, Otyugh, Pit Fiend).

The adjacent rule we already withdrew for the same reason: *"a row that imposes a
condition must offer a saving throw."* 40% of print's condition rows don't.
