first pass refused one answer of eighty — line 29, the Adult Red Dragon's "its blinded eye collapses
into a fist-sized red crystal" — for the Blinded condition. That was wrong: the GM had typed "blind
in one eye", the word is an ordinary adjective, and no creature gains anything. The validator now
reads a condition only as the rules term print writes, capitalized; the lowercase word is flavour.
That one refusal is the only thing in eighty lines that found a fault in the validator, and it is
now a test (`what-counts-as-a-ribbon.spec.js`). All eighty were re-validated against the corrected
rule — every one is a ribbon. No answer was re-asked and no text here was edited.
